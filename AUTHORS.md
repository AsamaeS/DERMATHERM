## 📚 Crédits Scientifiques

### Références Implémentées

Les équations et méthodologies implémentées dans DERMATHERM sont basées sur les travaux de recherche suivants :

#### Équations de Transport

- **Crank, J., & Nicolson, P.** (1947). A practical method for numerical evaluation of solutions of partial differential equations of the heat-conduction type. *Mathematical Proceedings of the Cambridge Philosophical Society*, 43(1), 50-67.

- **Courant, R., Friedrichs, K., & Lewy, H.** (1928). Über die partiellen Differenzengleichungen der mathematischen Physik. *Mathematische Annalen*, 100(1), 32-74.

#### Physics-Informed Neural Networks

- **Raissi, M., Perdikaris, P., & Karniadakis, G. E.** (2019). Physics-informed neural networks: A deep learning framework for solving forward and inverse problems involving nonlinear partial differential equations. *Journal of Computational Physics*, 378, 686-707.

- **Baydin, A. G., Pearlmutter, B. A., Radul, A. A., & Siskind, J. M.** (2018). Automatic differentiation in machine learning: a survey. *Journal of Machine Learning Research*, 18(153), 1-43.

#### Textile Thermal Properties

- Références issues des dossiers scientifiques intégrés (voir `src/data/dossierA.tsx` et `src/data/dossierB.tsx`)

## 🛠️ Technologies et Frameworks

DERMATHERM est construit avec d'excellents outils open source :

### Frontend
- [React](https://reactjs.org/) - UI library
- [Vite](https://vitejs.dev/) - Build tool
- [TypeScript](https://www.typescriptlang.org/) - Type safety
- [Lucide React](https://lucide.dev/) - Icons

### Backend
- [Node.js](https://nodejs.org/) - Runtime
- [Express](https://expressjs.com/) - Web framework
- [better-sqlite3](https://github.com/WiseLibs/better-sqlite3) - Database
- [Zod](https://zod.dev/) - Validation

### Services IA
- [Featherless AI](https://featherless.ai/) - Qwen LLM access
- [Firecrawl](https://firecrawl.dev/) - Web scraping
- [YouCam API](https://www.perfectcorp.com/business/youcam-api) - Skin observation

### Infrastructure
- [Docker](https://www.docker.com/) - Containerization
- [Nginx](https://nginx.org/) - Web server
- [GitHub Actions](https://github.com/features/actions) - CI/CD
